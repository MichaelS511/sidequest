# Sidequest

A small arcade break and task planner built with plain HTML, CSS, and JavaScript. Tasks, points, shields, and daily streak progress are saved in the visitor's browser with local storage.

## Run locally

Open `index.html` in a browser.

## Publish with GitHub Pages

In the repository settings, open **Pages**, choose **Deploy from a branch**, select `main` and the root folder, then save. The site is a static page and requires no build step.
